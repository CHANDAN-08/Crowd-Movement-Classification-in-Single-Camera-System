Understanding crowd behavior in public spaces is critical for ensuring safety and supporting effective surveillance. This project presents a single-camera video analysis framework that classifies segment-wise crowd movement into three categories: Converging, Diverging, or Stable. Using object detection and tracking to extract movement patterns from CCTV footage, the system computes a custom-designed dispersion metric based on centroid positions to measure how tightly or loosely the crowd is moving. A heuristic model analyzes dispersion trends to classify behavior, and its performance is further compared with a Random Forest classifier trained on engineered features derived from the same data. The heuristic model, while simpler, demonstrates high interpretability and robust performance, making it more suitable for real-world deployment. The system is tested on various crowd scenarios and is designed for extensibility, enabling future integration with larger datasets and real-time monitoring tools. This work offers a practical, scalable approach for offline crowd behavior analysis in urban surveillance environments.
